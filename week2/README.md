# Bio.motifs Codon Port

This directory contains the Codon port of BioPython's Bio.motifs package.

## Structure

- `bio_codon/motifs/` - Main motifs module
  - `__init__.py` - Core Motif class and functions
  - `matrix.py` - Position matrices (frequency, weight, scoring)
  - `minimal.py` - MEME minimal format support
  - `thresholds.py` - Threshold calculations for motif scoring

- `test.py` - Unified test file for both Python and Codon
- `report.md` - Implementation report
- `ai.md` - AI assistance documentation
