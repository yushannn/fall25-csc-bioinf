# AI Assistant Usage - Week 2

## Overview
I used GitHub Copilot and ChatGPT to help with porting BioPython's Bio.motifs package to Codon.

## How AI Helped

### Code Understanding
- Helped analyze BioPython source code structure
- Explained complex matrix operations and statistical calculations
- Identified key classes and methods that needed porting

### Implementation Assistance
- Suggested Codon-compatible syntax alternatives
- Helped with type annotations and error handling
- Generated boilerplate code for matrix classes

### Testing
- Suggested test cases based on BioPython's test suite
- Helped debug import issues between Python and Codon
- Provided examples of @test decorator usage

### Documentation
- Helped write clear docstrings
- Assisted with README structure
- Generated parts of this report

## What I Did Myself
- Decided overall project structure
- Manual testing and debugging
- Understanding assignment requirements
- Making final implementation decisions
- Git commit messages and version control

## Challenges with AI
- Sometimes suggested Python-specific code that didn't work in Codon
- Had to manually fix NumPy dependencies that AI included
- Needed to simplify overly complex suggestions
- AI-generated documentation was sometimes too verbose
- It is very important to double check each step

## Time Saved
AI probably saved me 3-4 hours of:
- Reading BioPython documentation
- Writing boilerplate code
- Debugging syntax issues
- Writing test cases

## Lessons Learned
- AI is good for understanding existing code
- Still need to understand the problem yourself
- AI suggestions need careful review for correctness
- Human judgment essential for design decisions
